# linearcs

Design notes for a possible 2D geometry library restricted to lines and
arcs (offsets and booleans are well-behaved for both; beziers and other
curves are not). `sample.jsx` sketches a JSX-based way to describe guides,
circles and polylines with kept references between them, for visualizing
dependencies and design intent.

Not implemented: there is no package.json or source here, only these notes
and the sketch.
