# Docs tool and unknown-option warnings

Give the chat model a way to look up the JSCAD API, and tell it when a call
passes an option the function does not take. Both come from one generated
API index. The target stumble: `roundedCuboid({ radius: 2 })` silently uses
the default `roundRadius` of 0.2 (3 of 5 baseline `rounded-box` runs), and
the model learns fluent's API by throwing errors (`gear`).

## Scope

1. A build-time API index of `@jscad/modeling`, `@jbroll/jscad-fluent` and
   `@jscadui/jscad-text`.
2. A `docs` tool that answers lookups from the index.
3. Unknown-option warnings on model code's calls, returned with `eval`.
4. Eval and prompt changes to use and measure both.

Out of scope: an in-app help page for users, image results for `view`,
checking options on transpiled OpenSCAD code.

## 1. API index

A generator, `packages/agent-loop/api/build-index.js`, writes
`packages/agent-loop/api/index.json` (committed, regenerated by
`npm run api-index -w @jscadui/agent-loop`; a test fails when the committed
file differs from a fresh generation).

Sources:

- `@jscad/modeling`: the JSDoc in the pinned checkout,
  `.deps-cache/OpenJSCAD.org/packages/modeling/src` (the version the app runs;
  `@jscad/modeling` resolves there). Every public function in `primitives`,
  `booleans`, `transforms`, `extrusions`, `expansions`, `hulls`,
  `modifiers`, `colors`, `measurements`, `curves`, `text` and `utils`,
  found through each namespace's `index.js` exports. Not `maths` or
  `geometries`.
- `@jbroll/jscad-fluent`: `dist/index.d.ts`, `dist/types.d.ts` and
  `dist/gen/Fluent*.d.ts` from the installed package: the `jf.*` factories
  and the methods of `FluentGeom2`, `FluentGeom3`, `FluentPath2` and the
  array classes.
- `@jscadui/jscad-text`: its exported functions' JSDoc in
  `packages/jscad-text/src`.

Entry shape:

```json
{
  "name": "primitives.roundedCuboid",
  "pkg": "@jscad/modeling",
  "signature": "roundedCuboid(options) → geom3",
  "description": "Construct an axis-aligned solid cuboid ... with rounded corners.",
  "optionsFirst": true,
  "options": [
    { "name": "center", "type": "Array", "default": "[0,0,0]", "description": "center of rounded cube" },
    { "name": "roundRadius", "type": "Number", "default": "0.2", "description": "radius of rounded edges" }
  ],
  "example": "roundedCuboid({size: [10, 20, 10], roundRadius: 2, segments: 16})",
  "sameAs": null
}
```

`optionsFirst` is true when the first JSDoc param is `options` (an object).
Fluent factories whose option type is the modeling function's carry
`"sameAs": "primitives.roundedCuboid"` and that entry's options; fluent
factories with extra keys (e.g. `cylinder`'s `wall`, `inner`, `outer`) list
their own. A namespace entry (`primitives`, `FluentGeom3`) lists its
members' names with one-line descriptions. Expected size 20-40 KB.

## 2. `docs` tool

Added to `TOOLS` in `packages/agent-loop/src/tools.js` (and the server copy):

```
docs({ query }) — Look up a JSCAD function's signature, options and
defaults, or list a namespace. Query a name (roundedCuboid,
primitives.roundedCuboid, jf.polygon, FluentGeom3.extrudeLinear) or a
namespace (primitives, booleans, FluentGeom2).
```

Answer, as text in the tool result:

- A function: signature, description, options with type and default, the
  example, and for fluent a "same options as" line.
- A namespace or class: member names with one-line descriptions.
- Bare names resolve across packages; ambiguity lists the candidates.
- No match: `{ ok: false, error: "no entry <query>; closest: a, b, c" }`
  with the three nearest names by edit distance.
- Each answer is capped at 3,000 characters, truncated with a note.

The lookup is a pure function in `packages/agent-loop/src/docs.js` over the
index, so the app and the eval answer identically. In the app it runs in
the page (no frame round trip). `aiBridge`/`main.js` `aiDeps` gains `docs`.

`prompt.md` Tool policy gains one line: look up an unfamiliar function's
options with `docs` before using it.

## 3. Unknown-option warnings

`withOptionChecks(api, table, warn)` in
`packages/agent-loop/src/optionChecks.js` returns a copy of the namespace
tree `api` in which each function that has an `optionsFirst` entry in
`table` is replaced by a wrapper. The wrapper: if the first argument is a
plain object, every key not in the entry's options calls
`warn({ fn, option, suggestions })` (suggestions: known options within edit
distance 3); then it calls the original with the same arguments and returns
its result. Functions absent from `api` are skipped (the manifold engine's
export shape differs from jscad's). Namespace objects are copied, never
mutated. The table is derived from the index at build time into a small
module (`api/optionTable.js`, names and option names only) so the frame
does not load the full index.

### Where it is installed

Model code must see the wrapped copy; library code must not, or internal
calls produce false warnings. Everything in the frame shares one cached
exports object per bundle URL, so the object itself is never wrapped.

- **Frame** (`packages/require/src/require.js`, at the return of a module
  load and the cache-hit path): when the requested name is
  `@jscad/modeling`, `@jscad/modeling-for-anchors` or
  `@jbroll/jscad-fluent`, and the requesting module's base is a project
  file (`base.startsWith(root)`) that is not a `.scad` file, return the
  wrapped copy, memoized in a `WeakMap` keyed by the real exports. The
  cache keeps the real object. Library bundles (fluent, model-tools,
  anchors, manifold internals), the `j$` OpenSCAD runtime and the worker's
  own lookups get the real object, as today.
- **Eval** (`packages/agent-loop/eval/backend.js` `createReadFile` CDN
  stub): for `@jscad/modeling` and `@jbroll/jscad-fluent`, the stub returns
  the wrapped copy of Node's module object, never mutating it (fluent and
  model-tools share that object).

The require hook takes the wrapper from the frame worker through a
registration function (`setUserModuleWrapper(fn)`), so `@jscadui/require`
stays free of agent-loop code; the frame worker registers
`withOptionChecks`.

### Reporting

- The frame worker keeps a per-run collector, reset at the start of
  `jscadScript` (top-level model code runs during require), deduplicated by
  `fn`+`option`, capped at 20 entries. `jscadMain`'s result gains
  `warnings` when non-empty; grid runs (`src_frame/gridRun.js`) merge them.
- `aiEvaluate.js` passes `warnings` through on the `eval` tool result:
  `{ ok: true, entityCount, warnings: [{ fn, option, suggestions }] }`.
- The eval backend collects the same way and returns `warnings` on `eval`
  and `writeModel`.
- The editor's own runs ignore `warnings` (no UI change).

## 4. Eval and prompt

- A fixture `misspelled-option`: "A 30 by 20 by 10 box with 3mm rounded
  edges"; targets dimensions [10,20,30] and a volume band that only
  `roundRadius: 3` meets.
- `grade.js` metrics gain `warnings` (count of warnings returned during the
  run) and `docsCalls`.
- The keep rule is unchanged. The change is judged on `rounded-box`,
  `gear` and `misspelled-option` rounds, failed calls and geometry error.

## Testing

- Index: generator output contains `primitives.roundedCuboid` with
  `roundRadius` default `0.2`, `jf.polygon`, `FluentGeom3.extrudeLinear`;
  committed index equals a fresh generation.
- `docs.js`: exact name, qualified name, namespace listing, fluent
  `sameAs`, no-match suggestions (`roundedCube` → `roundedCuboid`), the
  3,000-character cap.
- `optionChecks.js`: unknown key warns with suggestion and still calls the
  original with identical arguments; known keys do not warn; non-object
  first argument is ignored; functions missing from `api` are skipped;
  `api` is not mutated.
- `require.js` hook: a project-file caller gets the wrapped copy; a bundle
  caller, a `.scad` caller and a base-less caller get the real object; the
  cache holds the real object.
- Eval backend: a model calling `roundedCuboid({ radius: 2 })` returns
  `warnings`; jscad-fluent's own internal calls produce none.
- Frame e2e (`e2e/frame.spec.js`, via simple-ci): a run with a misspelled
  option returns `warnings` on both engines.
