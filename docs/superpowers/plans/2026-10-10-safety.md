# Safety batch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the three safety-critical pre-trial holes: a failed project read must fail the save instead of deleting the project, model code must not survive a source change in a reused frame worker, and hash-loaded scripts must not fetch with ambient credentials or treat `//host` as same-origin.

**Architecture:** Typed not-found errors so the write-through cache distinguishes "new project" from "broken read"; an app-supplied load-source label with frame-side fresh-pool reset on change; protocol-relative URLs treated as remote plus credentialless hash fetches.

**Tech Stack:** ES2022, vitest (node default; `/** @vitest-environment jsdom */` only where the existing tests already use it).

## Global Constraints

- Targets modern browsers only, ES2022+ with no polyfills.
- npm workspaces monorepo; run package-scoped vitest files, not the full OpenSCAD suite locally.
- TDD: failing test first, watch it fail, minimal code, watch it pass.
- `npm run lint` and `npm run typecheck` must stay exit 0.
- YAGNI: no retry logic, no new protocol messages beyond one options field, no CSP/deploy changes.
- Commit each task separately on the current branch (working in place per user choice).
- The pre-commit hook is red on a pre-existing unrelated failure (`apps/jscad-web/test/storage-rowboat.test.js`, tracked in `docs/backlog.md` Remaining issues). When scoped gates are green and the hook blocks only on that failure, commit with `--no-verify` and say so in the report.

```js
const writeThrough = async (projectId, path, content, options = {}) => {
  const store = backendFor(projectId, path)
  let files
  try {
    files = { ...(await store.readProject(projectId)).files }
  } catch (err) {
    // A project the backend never saw starts fresh; any other read
    // failure fails the save, so one offline blob fetch cannot delete
    // the rest of the project.
    if (err?.name !== 'NotFoundError') throw err
    files = {}
  }
  files[path] = content
  return store.writeFiles(projectId, files, options)
}
```

**Interfaces:**
- Consumes: `sendScript(workerApi, files, request)` (`src/scriptRuns.js:29-33`, request passed as `jscadScript` options); `entry.options` in the frame (`frameHost.js:261-272`, a clone of the script params); `pool.retire` / `slotOps.end` / `runs.leave` semantics (read `workerSlot.js:72-89` and `gridRun.js:213-239` before implementing).
- Produces: every non-scratch `jscadScript` carries `source` (`project:<id>` for `PROJECT_BASE` urls, else the url); the frame ends all workers and starts fresh when a sourced load arrives with a different source than the last loaded one. Scratch loads, same-source reloads, and sourceless loads (old senders, e2e) behave exactly as today.

**Constraints the implementer must honor (read the code, do not assume):**
- `slotOps.end` answers every held app request with `AbortError` (`workerSlot.js:75-89`): after a reset no app id may be answered twice and none left hanging. Assert posted app ids are unique in the tests.
- `runs.leave` detaches grid members; a fanned run with no members posts `frameWorkerTerminated` (`gridRun.js:233-235`). The reset must not recruit fresh workers into the dead run: do not call any join/recruit path during reset.
- `retire()` promotion must not supply the replacement: a promoted idle spare ran the old source. The replacement must be a fresh `start()`.
- Mirrored setup (inits, file map) is replayed onto the fresh worker by the existing `start({ replay: true })` path; the app sends `jscadSetFiles` before `jscadScript`, so the replay carries the new files. Do not clear `state.mirrored`.
- `heldMains` entries keyed by dead slots must be answered (`dropHeld` with `AbortError`), or those runs hang.

```js
const needsTrustCheck = (url) => {
  // Gzip data URLs are user-provided content, don't need trust check
  if (url.startsWith(gzipPrefix)) return false
  // A protocol-relative URL inherits the page scheme but names a remote host.
  if (url.startsWith('//')) return true
  // Relative URLs are same-origin (safe)
  if (url.startsWith('./') || url.startsWith('/') || !url.includes('://')) return false
  return true
}
```

