# View tool redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `view` return 1–4 off-screen mesh renders as provider-native image blocks the model can act on, without moving the user's camera.

**Architecture:** A request-spec module validates the camera array; an app-side view handler resolves part-name look-ats to centroids and renders off-screen with the eval's orthographic framing; the loop carries image parts past the text cap, prunes old images but keeps cameras, and each provider adapter maps images to its native shape; `view` is offered only to vision-capable models.

**Tech Stack:** JS ES modules, vitest, three.js off-screen framing (ported from `eval/render/page.html`), existing `packages/agent-loop` provider adapters.

**Spec:** `docs/superpowers/specs/2026-10-18-view-tool-design.md`

## Global Constraints

- Aim is ephemeral to one `view` call; the live user camera never moves.
- One call carries 1–4 camera specs; a failed view fails the whole request atomically as `{ok: false, error: {name, message}}`.
- Image size parameter defaults to 640x480; longest side over 768 is an error.
- `view` is offered only to vision-capable models.
- Image payloads bypass the 24,000-char `capToolResult`; `runTurn` keeps only the latest `view` result's images but keeps all returned camera JSON.
- Unknown or ambiguous part names are tool errors, never guesses.
- No renderable mesh is a tool error, never a blank image.

## Review Focus

- `views` omitted or empty defaults to one iso-front auto-fit, never a live-pose copy — test in Task 1.
- `size` larger than 768 on the longest side errors instead of rendering — test in Task 1.
- Look-at part path with `/`, `..`, or empty segments errors as unknown part — test in Task 2.
- Non-square 640x480 framing keeps the whole bbox with margin, not a stretched crop — test in Task 3.
- A 2D-only or empty build answers a tool error with no image parts — test in Task 6.
