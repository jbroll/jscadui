# Quickstart

Shortest path from a fresh clone to a running dev server.

## Prerequisites

- Node.js (see `.nvmrc` for the pinned version, if present)
- npm 10+

## Setup

```bash
npm run setup
```

This fetches pinned sources, installs dependencies, and prepares the OpenSCAD corpora.

## Run

```bash
npm run dev
```

This starts all dev servers via Turbo. Open the `apps/jscad-web` URL printed in the terminal.
